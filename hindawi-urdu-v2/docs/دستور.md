## ۱۔ ہندوی کیا ہے؟

ہندوی ایک ایسا نظام ہے جس میں آپ **اپنی زبان اور اپنے رسمالخط میں** پروگرام
لکھ سکتے ہیں۔ یہ محض الفاظ کی تبدیلی نہیں — پروگرام مرتب ہوتا ہے، چلتا ہے،
اور **debugger تک** آپ کے اپنے نام محفوظ رہتے ہیں۔

بنیادی اصول: تین محور، جو کبھی خلط ملط نہیں ہوتے۔

| محور | کیا ہے | کہاں |
|---|---|---|
| رسمالخط | لکھنے کا نظام | `Romenagri/` · `acii2uni` · `fltr_ur_hi` |
| زبان | پروگرامر کے الفاظ | `ilm/keywords.csv` کا اردو کالم |
| معیار | حسابی تصور | `ilm/constructs.csv` |

## ۲۔ نو شیلیاں

| شیلی | میزبان زبان | فائل |
|---|---|---|
| گرو | C | `guru/h2c_urdu.uhin` |
| شرینی | C++ | `shraeni/h2cpp_urdu.uhin` |
| پراتھا | BASIC | `praatha/h2b_urdu.uhin` |
| کرترما | Java | `kritrima/h2j_urdu.uhin` |
| سوچی | Python | `soochee/h2py_urdu.uhin` |
| شبد | lex | `shabda/h2l_urdu.uhin` |
| ویاکا | yacc | `wyaaka/h2yacc_urdu.uhin` |
| یَنتر | assembly | `yantra/h2y_urdu.uhin` |

ہر پروگرام کی پہلی سطر پر `<شیلی …>` لکھیں۔ یہی طے کرتا ہے کہ کون سا راستہ
چلے گا۔

## ۳۔ تنصیب

```
sudo ./install
cd Hindawi/guru && make
```

## ۴۔ پہلا پروگرام

```
<شیلی گرو>
#شامل <معیاری.س>
صحیح مرکزی()
{
	لکھو("السلام علیکم\n");
	واپس 0;
}
```

چلائیں:

```
./Hindawi/urducc examples/01-salaam.uhin
```

صرف تیار شدہ C دیکھنی ہو:

```
./Hindawi/urducc -s examples/01-salaam.uhin
```

الٹی سمت — موجودہ C کو اردو میں پڑھنا:

```
./Hindawi/urducc -r program.c گرو
```

## ۵۔ کلیدی الفاظ

| اردو | C | اردو | C |
|---|---|---|---|
| اگر | if | ورنہ | else |
| جبتک | while | برائے | for |
| کرو | do | واپس | return |
| صحیح | int | حرف | char |
| اعشاری | float | دوہرا | double |
| خالی | void | ثابت | const |
| ساخت | struct | اتحاد | union |
| توڑو | break | جاری | continue |
| انتخاب | switch | صورت | case |
| لکھو | printf | پڑھو | scanf |
| شامل | #include | مرکزی | main |

پوری فہرست: `Hindawi/keywords`

## ۶۔ راستہ — اندر کیا ہوتا ہے

```
program.uhin
  ↓ fixuninum        دیوناگری ہندسے
  ↓ fixarabnum       عربی ہندسے ۰-۹  ← یہ خلا پُر کیا گیا
  ↓ fltr_ur_hi       اردو → ہندی
  ↓ iconv | uni2acii | acii2cf     رومیناگری
  ↓ h2c_urdu         کلیدی الفاظ → C
  ↓ cc               مرتب
```

**اہم:** تیار شدہ `.lex` کو کبھی `h2c` سے نہ گزاریں۔ ایسا کرنے سے pattern کالم
بھی بدل جاتا ہے اور تمام قواعد ناکارہ ہو جاتے ہیں۔

## ۷۔ نچلی سطح تک

```
./Hindawi/urducc examples/03-ساخت.uhin
objdump --dwarf=info 03-ساخت | grep DW_AT_name
```

`DW_AT_name` میں آپ کے اپنے نام نظر آنے چاہئیں۔ یہی اصل پیمانہ ہے —
صرف مرتب ہو جانا کافی نہیں۔

## ۸۔ اپنی زبان شامل کرنا

`ilm/worksheets/<زبان>.csv` میں صرف وہ تصورات ہیں جن کا ترجمہ باقی ہے۔ کالم
بھریں، `ilm/keywords.csv` میں واپس رکھیں، اور:

```
node tools/gen_perso_shaili.mjs <زبان>
```

ترجمے کی تکمیل کبھی رکاوٹ نہیں — یہ صرف حالت ہے، دروازہ نہیں۔

## ۹۔ معلوم خامیاں

- `praatha` کا میزبان `qb2c` ہے جو صرف QuasiBASIC سمجھتا ہے؛ ہر BASIC ساخت نہیں چلے گی۔
- `#line` ہدایت ابھی خارج نہیں ہوتی، اس لیے مرتب کرنے والے کی غلطی تیار شدہ
  فائل کی سطر بتاتی ہے، آپ کی `.uhin` کی نہیں۔ یہ خلا موجود ہے اور چھپایا نہیں گیا۔
