Not official GATE papers. Each bullet has a **running** function in `src/panini/gate/`.

| Official section | Official bullets | PANINI file |
|---|---|---|
| 1 Engineering Mathematics | logic, sets/relations, groups, graphs, combinatorics, recurrences, matrices, eigenvalues, calculus extrema, mean/variance, Bayes | `01_math.pni` |
| 2 Digital Logic | Boolean, combinational, sequential, minimization, number/arithmetic | `02_digital.pni` |
| 3 Computer Organization | instructions, addressing, ALU/datapath, pipeline+hazards, cache/memory, I/O interrupt/DMA | `03_coa.pni` |
| 4 Programming and DS | C-shaped recursion, arrays, stacks, queues, linked lists, trees, BST, heaps, graphs | `04_ds.pni` |
| 5 Algorithms | search, sort, hash, complexity counters, greedy, DP, D&C, BFS/DFS, MST, shortest paths | `05_algo.pni` |
| 6 Theory of Computation | RE/FA, CFL/CFG/PDA, pumping, TM, undecidability marker | `06_toc.pni` |
| 7 Compiler Design | lex, parse, SDT, runtime, TAC, const-prop, liveness, CSE | `07_compiler.pni` |
| 8 Operating System | syscalls/process/thread/IPC, sync, deadlock, CPU/I/O sched, VM, FS | `08_os.pni` |
| 9 Databases | ER, RA/SQL, constraints/NF, files/B+, tx/CC | `09_dbms.pni` |
| 10 Computer Networks | OSI/TCPIP, switching, DLL/MAC, routing, IPv4/CIDR/NAT, TCP/UDP, DNS/HTTP | `10_networks.pni` |
