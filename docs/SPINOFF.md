This repository hosts siblings **until they move**. Each `apps/<name>/`
is a future repo root. Pages copies live under `docs/<name>/` so GitHub
Pages works today.

| In this tree | Spins off to | Notes |
|---|---|---|
| `apps/zistgah/mez/` + `docs/mez/` | `zistgah/mez` | Desk. PANINI program `stdlib/mez.pni` |
| `apps/zistgah/fakir/` + `docs/fakir/` | `zistgah/fakir` | Domain lattice, not the 90MB dome |
| `apps/zistgah/cycles/` | `zistgah/cycles` | Cycler .pni corpus |
| `apps/project-ilm/ilm.codes/` | `project-ilm/ilm.codes` | Site migration |
| `apps/hindawiai/hindawi-legacy/` | `hindawiai/hindawi-legacy` | Pointer, not DOS binaries |
| language core | `zistgah/panini_by_grok` | stays |

Do not mix mez Python stdlib desk (`./mez serve`) with PANINI JS interpreter
in one process. The Pages mez is the 2D rung. Console rung stays Python in
`zistgah/mez`.
