Complete roadmap

Twelve points plus the ISA matrix. Linux, Boost, AOSP, QEMU are named, not claimed. llama.cpp’s restricted C/C++ is the workload this lowering is tuned for.

ROADMAP.md Lowering notes STANDARD GREEN

12 points

  1. Linux kernel — GNU C pre-pass is in runtime/gnuc.js. vmlinux does not build. Needs asm volatile JIT + .lds.
  2. Binutils — ELF/object notes. Not GNU ld.
  3. Android — Bionic as a target. Not AOSP.
  4. QEMU — named guest list. Not QEMU.
  5. CUDA on host — detect NVCC, skip WASM. No CUDA in this zip.
  6. WGSL in browser — runtime/wgsl.js emits a matmul shader. Not ggml-GPU.
  7. Frontend keep-fit — STANDARD GREEN harnesses + tests/test.mjs (exit 0).
  8. BLAS + autotune — stdlib/blas.pni. Not OpenBLAS. SIMD later.
  9. x86 on VFS — v86 guest live. SoftMMU + virtio-blk designed, not booting Linux.
  10. Resource monitor — runtime/monitor.js.
  11. Refactor — unified lowerers into C AST. One run_c.
  12. Linguistic equity packs — ILM tables retrieved, not invented. Dialects via cycler deposits.
