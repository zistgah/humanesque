Local Hindawi

The same compiler people ran as Hindi C on a 486, unzipped from this tree, modernized. Not 22 copies. Not #define.

cd dist/hindawi
./configure --prefix=$HOME/.local
make
make check
make install
guru examples/hindi/guru.uhin

Driver: tools/hincc.mjs. Wrappers: guru, shraeni. Host is GNU11 gcc. UTF-8 identifiers are allowed. #समावेश <मानकपन.स> becomes #include .

Architecture

script table     language table      shaili table
(flatten reverse) (native ↔ C)        (Guru / श्रेणी / …)
        \              |                   /
         \             v                  /
          \     Devanagari hub          /
           \           |               /
            →  shaili lex → host → cc

Hindi is the retrieved shaili. Other languages are projections of that kernel. Brahmi letters flatten. Perso-Arabic is named lossy. Manipuri and Santali wait for a CSV in deposits/csv — they are not invented here.
