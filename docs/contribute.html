How a pull request is judged correct. Automated first. Human signoff on named GAPs.

Contribute

PANINI is GPL-3.0-or-later. Copyright 1993–2026 Abhishek Choudhary. Retrieve, do not reconstruct. Consult factory/REGISTRY.json before adding a file. Frozen hashes stay frozen.

What a pull request must pass

  1. node scripts/pr_gate.mjs — correctness gate. Non-zero exit fails the PR.
  2. AyeBIOS guest boots offline. Text contains AYEBIOS. Floppy 55AA. Mode 13h gold bar on key V.
  3. Vesoha Hindi tables: one TSV per frontend in frontends.json, every catalog keyword present.
  4. STANDARD GREEN index: 45 / 45, CORE 0. Named official extract skip=0. Homemade 20-case is CORE only — do not relabel it.
  5. emu.html does not load copy.sh / unpkg. The guest is local.
  6. Do not edit frozen workbench chrome. Add a frontend by appending data/frontends.json.
  7. Do not invent keyword maps in retrieved/.

How CI runs it

GitHub Actions workflow .github/workflows/pr.yml runs the gate on every pull request. A PR is correct when the gate exits 0 and the named STANDARD GREEN harnesses for touched frontends stay skip=0.

node scripts/pr_gate.mjs
node scripts/core_std_green.mjs      # named extracts
node scripts/remaining_std_green.mjs

Manual checks (the rest of the test plan)

  • Home menu present. Workbench Run on C returns 42.
  • x86 guest: Boot, Hindi banner, floppy editor apply hex, re-boot.
  • Vesoha page lists 45 tables.
  • Packages page packs a .panini-pkg.json.
  • local.html zip downloads. Chat also surfaces the zip.
