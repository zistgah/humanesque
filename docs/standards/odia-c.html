Compile path

  1. Unicode source (this page).
  2. Flatten to the Devanagari hub (Brahmi). Perso-Arabic applies the language table first, then urdu_map, and is lossy.
  3. Original Romenagri: Unicode → ACII (unicode_hin) → Romenagri (acii_chrt / retrieved legacy/Romenagri/acii2rmn.lex). Binding: engine/romenagri-orig.js + canonical_basis.json.
  4. Shaili lex on that ASCII-7 kernel.
  5. Host C. The shaili pragma is removed. It is not a host token.
