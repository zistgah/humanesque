Call to action

Hindi guru has been public since 15 August 2004. The keyword table is the standard. English ISO wording is not.

If you know a better word, a dialect, or a missing Eighth Schedule language: send a CSV. Do not send a #define header.

How a standard is published

  1. CSV lands in deposits/inbox/ or the folders above.
  2. A later turn checks: unique natives, no invented cuneiform, pipeline still Unicode → ACII → Romenagri → lex.
  3. scripts/gen_standards.py fills docs/standards/-c.html.
  4. The page is the published standard. The TSV remains the normative table.

Viewing (not compiling)

A program in Hebrew C can be viewed as Hindi C. Keywords follow the two standards. Variable names follow the identifier dictionary. Compilation still uses the original file.

If you do not know the author’s identifiers, you see id_1 … and the original in the dictionary. You may attach a glossary. The system does not invent translations of names.
