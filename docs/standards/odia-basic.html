  6. Viewing does not change compilation identity.
  7. Identifiers are presented through a dictionary. Compilation uses the original identifiers.

  10. Corrections are submitted as CSV in deposits/csv and deposits/standards.

Compile path

  1. Unicode source (this page).
  2. Flatten to the Devanagari hub (Brahmi). Perso-Arabic applies the language table first, then urdu_map, and is lossy.
  3. Original Romenagri: Unicode → ACII (unicode_hin) → Romenagri (acii_chrt / retrieved legacy/Romenagri/acii2rmn.lex). Binding: engine/romenagri-orig.js + canonical_basis.json.
  4. Shaili lex on that ASCII-7 kernel.
  5. Host BASIC. The shaili pragma is removed. It is not a host token.

Host after compile

Shaili pragma stripped from host. Host is BASIC.

INPUT "ऊँचाई: ", न
PRINT न
FOR क = १ TO न
	FOR ख = १ TO (न - क)
		PRINT " ";
	NEXT ख
	FOR ग = १ TO क
		PRINT "&";
	NEXT ग
	PRINT ""
NEXT क
FOR क = (न - १) TO १ STEP -१
	FOR ख = १ TO (न - क)
		PRINT " ";
	NEXT ख
	FOR ग = १ TO क
		PRINT "&";
	NEXT ग
	PRINT ""
NEXT क
END
