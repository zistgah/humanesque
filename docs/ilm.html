Three axes, never conflated

A cell is (script × language × standard). Collapsing any two is the error that produces #define je if — a macro that evaporates at the preprocessor and reaches no diagnostic, no debugger and no symbol table.

A skeleton is not a gap in the machinery. Its romenagri and host-keyword columns are filled from retrieved data; only the native column is empty, marked UNRESOLVED — a speaker must author them. One TSV per language brings the whole toolchain alive for it. A wrong Kashmiri keyword would be worse than an absent one.

Reproduce it

node tools/extract_maps.mjs        # nine shailis from the transducers
node tools/build_ilm_matrix.mjs    # 27 languages x 9 shailis

Both read only files on disk under retrieved/. Every map asserts "invented": false, and VERIFY.sh checks it.
