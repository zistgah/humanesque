# PANINI v3 Workbench (L15)

Static only. GitHub Pages. No custom backend.

## Enable Pages

Repo Settings → Pages → GitHub Actions.

Workflow: `.github/workflows/pages.yml` publishes `website/`.

## Local

Open `website/index.html` or serve `website/`.

VS Code: Extensions → Install from VSIX not packaged; open `tools/vscode-panini` as an extension development host.

Diagnostics: `node tools/panini-lsp/cli.mjs file.pni`
