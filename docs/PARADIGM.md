## Not another programming language

Conventional PLs occupy **one region** of a configuration space (imperative, functional, logic, …).

PANINI treats that taxonomy **as the configuration space**. The 13-axis thesis, scoped paradigms, and typed boundaries are how it *moves* across regions. That is the new paradigm:

```
(Script × Paradigm × Axis Configuration) → Canonical IR
```

Representation ⊥ computation (ILM × PANINI). Linguistic equity is architecture.

## The evening’s problem (why this release)

LLMs reduce linguistic diversity and erase identity signals in writing
(Nature Human Behaviour line of work; public discussion e.g. Capraro 2026,
paper https://arxiv.org/abs/2502.11266).

If the only computational path is “translate into English, ask a model,
translate back,” identity is stripped at the preprocessor — the same
category error as `#define je if`.

**Proposed solution:** ILM (representational equity) + PANINI (computational
equity) + mez cyclers (no-API harness) so a community can compute *in* its
substrate, with provenance, not through a privileged language.
