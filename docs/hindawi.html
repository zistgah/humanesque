Build: cd guru && make then ./gurucc ../samples/01-namaste.uhin. A <शैली …> line selects the pipeline.

The transducers compose. shabdacc runs h2l | h2c and wyaakacc runs h2yacc | h2c — a lex or yacc action block is C, so those shailis inherit the C vocabulary. Reading one alone reports a working shaili as a broken one.

Keyword provenance

Every keyword carries how it got there, and every one is editable — edit guru/h2c.uhin and re-make.

tagmeaning
tsv csvretrieved table
inherited:Xvocabulary of a language in the same script and register
projected:Xmapped character-wise through this script's own transliteration table
projected-partial:Xat least one character had no mapping and was carried through unchanged
A starting vocabulary a speaker corrects — not a claim of authority, and not left empty either. An empty table helps nobody.
