Devanagari flow — how Hindawi localizes a language

Two independent axes. Mixing them was the earlier error.

Load a demo and run it

2004 samples. Compile with retrieved h2c/h2b. The browser interprets the host; gurucc ends in gcc and has produced binaries since 2004.

1. Script substrate (all Devanagari languages share this)

Devanagari Unicode
        │  retrieved unicode.h (73 signs)
        ▼
      ACII  (8-bit phonetic; one layer for all Indic)
        │  retrieved acii2rmn.c (stack: implicit a, matras pop it)
        ▼
    Romenagri ASCII   मुख्य → mukhya    अ → _a    क → ka
        │
        ▼
  gcc / debugger see C-legal identifiers
  APCISR paints the same ACII as Devanagari in true text mode

Strings stay UTF-8. Identifiers never become English names. That is how you debug at the hardware in the vernacular.

2. Shaili (शैली) — which host language

Not Hindi vs Nepali. Which compiler you are localizing. Each is a retrieved lex filter:

Praatha writes the lex in Devanagari (लिखो {printf("PRINT");}). Guru writes it in Romenagri (mukhya {printf("main");}) after acii2rmn. Same idea, different layer.

3. Bhasha — which vernacular on that script

Hindi, Nepali, Marathi, Sanskrit all write Devanagari. They do not share C-keyword words. Retrieved TSVs:

Hindi     यदि / लौटाओ     → if / return
Nepali    यदि / फर्काऊ     → if / return
Marathi   जर  / परत       → if / return
Sanskrit  यदि / प्रत्यागम  → if / return   (keyword-by-keyword; not a Paninian parser)

Executed:

यदि (1) { लौटाओ 0; }      →  if (1) { return 0; }
यदि (1) { फर्काऊ 0; }     →  if (1) { return 0; }
जर (1) { परत 0; }        →  if (1) { return 0; }
यदि (1) { प्रत्यागम 0; }   →  if (1) { return 0; }

4. Proof on retrieved samples

Guru / HindiC.uhin

पूर्णांक मुख्य()           →  int main()
अक्षर अ[]               →  char _a[]
म_लिखो("…")            →  printf("आपका नाम क्या है?\n")
क्रम(क=1; क<=10; क++)   →  for(ka=1; ka<=10; ka++)
वापस 0                  →  return 0

Praatha / HindiBASIC.uhin

पूछो "ऊँचाई: ", न   →  INPUT "ऊँचाई: ", न
लिखो न               →  PRINT न
क्रम क = १ से न      →  FOR क = १ TO न
क्रमांत ख             →  NEXT ख

Leftover न, क stay for the identifier/Romenagri step. Indic digits १ are not in unicode.h’s 73 rows — reported, not invented.

5. What this is not

  • Not Gurmukhi→Devanagari as the localization of C.
  • Not an 8-word if→यदि toy in the linguist pane.
  • Not a Sanskrit grammar engine. Sanskrit here is the keyword TSV only.
