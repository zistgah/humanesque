Classifications

  • STANDARD GREEN — issuing-body spec ∧ that body’s executable suite, skip=0. See STANDARD_GREEN.md.
  • CORE GREEN — homemade factory 20-case smoke. Not a standard.
  • NAMED GAP — spec retrieved, suite not skip=0 (Fortran execute, Go all.bash, Rust rustc ui, Zig, Lua).
  • Museum stub — languages/*.pni axis character. Not a compiler.

On the site they lower to host C, then C → WASM. Python uses the AST. Braced languages use a numeric subset transducer (to_c.pni). Proven: compute(5)=25 for Python, Rust, Go, TypeScript, Zig, Lua, C++.
