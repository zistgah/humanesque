Three hurdles

  1. Stack vs memory. Trees become postfix. x + 10 * 2 → get x; const 10; const 2; mul; add.
  2. Strict i32. The validator rejects C’s implicit casts. Lowering inserts typed ops.
  3. One linear memory. $heap bump is calloc. $sp grows down. Pointers are i32 offsets. i32.load / i32.store.

Maṇḍūkapluti (goto): a function without it stays on structured if/loop. A function with it lowers to a CFG and a br_table dispatcher. Peephole deletes jumps to the next block. Relooper is named, not this turn. WASM_MANDUKAPLUTI.md · wasm-cfg
