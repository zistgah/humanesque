## 1. End state

Linguistic equity is architecture, not a campaign:

```
Representational equity  ↔  ILM   (L12)
Computational equity     ↔  PANINI (L13–L14)
Tooling / workbench      ↔  mez + this site (L15)
Retrieval                ↔  FAKIR
Harness                  ↔  cyclers (no vendor API)
Sovereignty              ↔  Humanesque / POIE (L25)
```

Hindawi, since 2004, localises a host language through the **lexer** and emits
**machine code** (`gurucc` ends in `gcc -o hin.exe`). PANINI treats the conventional
PL taxonomy as a **configuration space**. The workbench is L15 of the retrieved
interoperability stack, not an unrelated product.
