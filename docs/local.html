Download panini.zip

What is in the zip

  • panini/ — compiler, runtime, retrieved Hindawi 2004 / Romenagri, examples.
  • panini/docs/ — this website: notebook, workbench, language stacks.
  • panini/PACKING.txt — what was left out, and why.

What is not in the zip

Named, not hidden. These are large and already published elsewhere:

  • ISO / ECMA specification PDFs and HTML dumps (n1570, n4296, ECMA-262, …). Fetch them from the issuing body.
  • GGUF models and WASM guests. The story spinner and llama.cpp page fetch those at run time.
  • AyeBIOS firmware blobs.

Web host (JavaScript)

unzip panini.zip
cd panini
node src/cli.js run examples/hello.pni
node src/cli.js compile examples/factorial.pni --target c --out factorial.c

Native binary (PANINI → C → gcc)

JavaScript is primary because the web is primary. The same programme compiles to a machine binary on the local CLI.

node src/cli.js binary examples/factorial.pni --out factorial
./factorial
# prints 720

Equivalent: node src/cli.js gcc examples/factorial.pni --out factorial

Requires node and gcc on the PATH. The emitted C is the GNU11-shaped integer subset.
