Web-built artifacts. Same IR, two backends: WASM and local gcc.

Package and distribute

What you build here is a package: source, frontend, backend choice, and the emitted artifact. Download it. On a machine with node and gcc, the local backend is panini binary.

Source

idle

Install locally

unzip panini.zip
cd panini
chmod +x bin/panini
./bin/panini run examples/hello.pni
./bin/panini binary examples/factorial.pni --out factorial
./factorial
./bin/panini package examples/hello.pni --backend local --out hello.panini-pkg.json
